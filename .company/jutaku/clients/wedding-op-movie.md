## 2. ヒアリングシート(次の連絡で埋める)

### 最優先(これが埋まらないと見積もれない)
- [ ] **挙式日**(→ 逆算した制作締切。会場提出は式の1〜2週間前が一般的と言われているため、実質の締切は挙式日ではない)
- [ ] **会場名と会場の映像規定**: 納品形式(DVD / Blu-ray / データ)・アスペクト比・解像度・提出締切・**持ち込み料の有無**・試写の可否
- [ ] **予算感**(先方の想定金額。有償か、ご祝儀代わりの無償・格安かも含む)
- [ ] **依頼者との関係**(友人/親族/知人紹介/仕事の紹介)→ 金額と断りやすさが変わる

### 制作条件
- [ ] 希望の尺(OPは1分30秒〜2分程度が一般的。長すぎると進行を圧迫する)
- [ ] 上映タイミング(新郎新婦入場前が定番。会場の進行表と合っているか)
- [ ] テイスト(感動系/コミカル/映画予告風など)と**参考にしたい既存動画のURL**
- [ ] BGM: 希望曲は市販曲か。**市販曲の場合は会場側で楽曲使用の申請(ISUM等)が必要になるケースがあるため、会場に確認が必要**。難しければフリー音源・著作権処理済み音源から選ぶ
- [ ] 素材: 写真の枚数・動画素材の有無・解像度・**受け渡し方法と提出期限**
- [ ] テロップに入れる文言(名前の表記、日付、メッセージ)の確定版を誰が出すか
- [ ] 修正回数の上限(こちらから2回までを提示する前提)

### 事業判断用
- [ ] **事例として公開してよいか**(顔出しNGなら構成やメイキングのみの公開可否)→ モニター価格の交換材料になる
- [ ] 同じ式で他の映像(プロフィールムービー/エンドロール)の依頼もあるか → まとめて受けると単価が上がる

## 3. スコープ案(合意時にそのまま契約文言にする)

**含むもの**
- 構成案の作成(1案)、素材の選定・整理、編集、テロップ、BGM合わせ、書き出し
- 修正2回まで(初稿提出後)
- 会場規定に合わせた形式での納品1回

**含まないもの(別途見積もり)**

- 当日の会場での機材オペレーション・立ち会い
- 会場への持ち込み料、DVD/Blu-rayメディア実費、有料音源・楽曲申請費用(実費は依頼者負担)

**前提条件(遅延の責任を切り分ける)**

## 4. 金額の考え方(※相場は未検証。提示前に要調査)

- 現メニューでは「ショート動画編集: 応相談」しかなく、**結婚式映像の値付けルールが社内にない**。
- 制作会社とフリーランス/スキルマーケットで価格帯が大きく違う領域と言われているが、**うちでは実勢を調べていない**。提示前にココナラ等で同種出品を10件観察して決める(TODO化済み)。
- 判断軸のたたき台:
  - 想定実工数は**10〜15時間**(ヒアリング・構成・素材整理・編集・修正2回・納品)。副業の受託枠(週16h)の1週間分に近い。
  - この工数を時給換算して下回る金額なら、**受けること自体が赤字**。知人価格で受けるなら「いくら分を贈っているか」を自覚した上で決める。
  - 値引きする場合は憲法どおり**「事例公開OKとの交換=モニター」の形のみ**。無条件の値引きはしない。

## 5. 受けるかどうかの論点(オーナー判断)

**受ける理由になりうるもの**
- 現金化までが早い(単発・前払い交渉可)。フェーズ1の目的に合う
- 「納品して喜ばれた実績」が1件できる。受託の初案件が0件の現状では意味がある
- 動画制作の工程を1本通しで経験できる → YouTube部門・SNS部門の内製力に直結する

**受けない/慎重にすべき理由**
- **本業ニッチ(治療院・サロン×LINE×広告)から外れる**。受託部門の戦訓「単体スキルの動画編集は低単価の競合が多い」に真正面からぶつかる案件
- **納期が動かせない**。副業稼働で式の直前に本業が繁忙になると詰む。バッファを2週間は取りたい
- 知人案件は値切られやすく、修正無制限になりやすい。**最初にスコープと修正回数を文字にできないなら受けない**
- 会場規定の確認漏れ(形式・締切・持ち込み料)は当日事故に直結する。ここは絶対に手を抜かない

**ジーナの見立て**: 「単発で受けて、以後は本線(LINE×広告)に戻る」なら賛成。ただし**①挙式日まで1ヶ月以上ある ②スコープと修正回数を先に文字で合意できる ③会場規定を先に確認できる** の3つが揃うことが条件。1つでも欠けるなら、正直に断るか、別の制作者を紹介する方が信頼を落とさない。
