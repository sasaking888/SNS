## 2. ターゲット（読む人）

**発注する人ではなく、社内で稟議を上げる人が読む。**

- **主読者**: 従業員30〜300名規模の企業の**総務・人事・経営企画**の担当者
- **状況**: 福利厚生の見直し、健康経営の施策探し、離職率や採用力の課題を上から降ろされている
- **不安**: 「場所を取るのでは」「業務が止まるのでは」「稟議が通る金額か」「効果を説明できるか」
- **検索語**: 出張整体 法人 / オフィス 整体 福利厚生 / 健康経営 施策 / 企業 出張 リラクゼーション

→ **LPの役割は「上司に説明できる材料を渡すこと」**。感情訴求より、スペース・時間・金額・導入実績を明快に出す。

## 3. 訴求の骨格

### ファーストビュー（モックから改稿）

モックの「社員が元気だと、会社は強くなる。」は綺麗だが**何屋か分からない**。B2Bのファーストビューは「誰に・何を・どうなる」を即答させる。

```
サブ   : オフィスに、健康という投資を。
主見出し: 社員が元気だと、会社は強くなる。
サービス: 企業出張整体 CHARGE OFFICE ← モックより大きく、主見出しの直下に
補足   : 半畳のスペースとひとり10分。業務を止めずに導入できる福利厚生です。
CTA    : まずは無料トライアルから（副: 資料をもらう）
安心材料: 相談・見積もり無料 ／ グループ累計12万人以上の施術実績
```

「企業出張整体」を**主見出しと同じ視線の中に入れる**のが必須要件。

### 3つのバッジ（ファーストビュー直下・モック踏襲）

| | 見出し | 本文 |
|---|---|---|
| 省スペース | たった0.5畳分のスペースでOK | |
| 高回転 | おひとり約10分・1時間で約5名 | |
| 高品質 | **グループ累計12万人以上**の施術実績 | ← 数字と主語を修正 |

## 5. 料金セクション（新規）

**法人担当者は概算がないと稟議を回せない。** 「要問い合わせ」だけにしない。

```
見出し: 料金
本文  : ご利用人数と頻度に応じたプランをご提案します。

  【プランA】月◯回コース   ¥【金額】/ 回（◯名まで）
  【プランB】月◯回コース   ¥【金額】/ 回（◯名まで）

  ・初期費用【あり／なし】
  ・お見積もりは無料、最短【◯】営業日でご提示します
  ・まずは無料トライアルで、費用感と現場の反応をご確認ください
```

→ **実額はクライアント確認待ち**（§9）。金額を出せない場合でも「見積もり無料・最短◯日提示」は必ず入れる。

## 6. 表現ルール（法令・必ず通す）

### 禁止語リスト

| 使わない | 理由 | 言い換え |
|---|---|---|
| マッサージ | 無資格者が含まれるため、あん摩マッサージ指圧師法にかかり得る | 整体／施術／ほぐし |
| 治る・治療・改善します | 医業類似行為の効果標榜 | ケアする／整える |
| 国家資格者が施術します | 全員ではないため誤認 | **国家資格保有者が在籍しています** |
| 離職率が下がります／生産性が向上します | 因果が立証されていない（優良誤認） | 〜につながると言われています／〜を目指します |
| 必ず・絶対・誰でも | 共通憲法の禁止事項 | — |

### 導入メリット6項目の書き換え

断定形をすべて落とす。出典を付けられるものは付ける。

| モック（断定） | 修正後 |
|---|---|
| 生産性向上 | 生産性の向上を目指して |
| 従業員満足度向上 | 従業員満足度の向上に |
| 離職率の低下 | 離職率の低下につながると言われています |
| 健康経営の推進 | 健康経営の取り組みとして ※商標確認（§9） |
| 採用力アップ | 採用時のアピール材料に |
| 社内コミュニケーションの活性化 | 社内コミュニケーションのきっかけに |

### 数字の扱い

- **「グループ累計12万人以上」** — 主語（グループ）を省略しない。CHARGE OFFICE単体の数字と誤認させない
- 効果に関する数値（CVR改善率など）は**出典なしに載せない**

## 7. お客様の声の掲載条件

実在の導入企業の声があるとのことなので、**掲載前に以下を満たすこと**。

- [ ] 各社から**掲載許諾**を取得（匿名掲載でも必要）
- [ ] 業種・部署名の表記について許諾範囲を確認（「IT企業 人事部」までOKか）
- [ ] 発言内容を要約・編集した場合、**趣旨を変えていない**ことを本人確認
- [ ] 効果に触れる声（「生産性が向上した」等）は**個人の感想である旨**を併記

許諾が揃わない声は**載せない**。1件でも実名・許諾付きがあれば、3件の匿名より強い。

## 8. デザイントークン（Figma → Grok build 受け渡し用）

/* 書体 — クライアントにブランドフォント指定があればそちらが優先 */

/* 数値 */

### デザイン上の指示

- **実写に寄せる。** モックはお悩みセクションがイラスト、他が実写でトーンが割れている。実写素材があるなら統一する
- **カードの入れ子をしない。** モックの「導入メリット6項目」はカード内カード気味。1階層に落とす
- 影は控えめに。グラデーションの光球・過剰なアニメーションは入れない
- **モックと1px合わせをしない。** 実装後に見るのは①ファーストビュー訴求 ②CTA周辺 ③フォーム導線の3点のみ

## 9. 実装要件

- **レスポンシブ必須。** 法人担当者もスマホで下見する。ブレークポイント 720px / 1024px
- **電話CTAはスマホで `tel:` リンク**（050-3184-3852）。PCでは文字表示のみ
- **フォーム項目は最小限**: 会社名／担当者名／メールアドレス／電話番号／従業員数／相談内容。**項目を増やすほど落ちる**
- **フォームはファーストビュー以外に最低3箇所からたどり着ける**（03バッジ下・08料金・15最終CTA）
- 追従CTA（スマホ下部固定バー）を推奨
- 計測タグの設置有無は**クライアント確認**（GA4／広告タグ）
- FAQは素の `<details>` で実装可。JSを足さない
- 特商法・プライバシーポリシーのページ有無を確認（フォームで個人情報を取得するため**プライバシーポリシーは必須**）
