# LP制作キット — クレジットを減らさない作り方

LPをAIに作らせるとクレジットが急に減る。原因はセンスでも枚数でもなく、**作り方の構造**にある。
このフォルダはその構造を直すための型。作業前にここだけ読めばよい。

## なぜ減るのか(4つの原因)

| # | 原因 | 何が起きているか |
|---|------|------------------|
| 1 | **1枚の巨大HTMLを毎回まるごと読み書きする** | 1000行のLP ≒ 1.5万トークン。1往復で「読む＋書き直す」だけで約3万。4往復で12万が消える |
| 2 | **「全体的に良くして」と頼む** | 名指ししないとAIは全文を書き直す。1文字の修正でも全額かかる |
| 3 | **毎回デザインをゼロから決め直す** | 色・書体・余白の検討と生成を案件ごとに繰り返している |
| 4 | **reasoning effort を上げる** | 考えすぎて全書き換えに走り、コストだけ増える(low〜mediumが強い) |

## この型での対策

1. **セクション分割** — 直すのは該当ファイル1枚だけ。hero を直すなら `sections/20-hero.html`(約10行)。往復コストがおおよそ1/10になる
2. **トークンとCSSの凍結** — `tokens.css` / `base.css` は一度決めたら触らない。案件ごとに変えるのは基本 `--c-accent` の1行だけ
3. **一括ブリーフ** — `brief.md` を先に埋める。質問と推測の往復が消えて初稿が近くなる
4. **単一ファイル出力** — `./build.sh` で `index.html` を生成。納品・アップロードは1枚で完結する

## 手順(1案件あたり)

```sh
cp -r .company/affiliate/lp/_template .company/affiliate/lp/<案件名>
# brief.md を埋める → 各 sections/*.html の【】を埋める → 不要セクションは削除
cd .company/affiliate/lp/<案件名> && ./build.sh
```

初稿ができてからブラウザで確認 → 修正 → `./build.sh` を回す。**3〜4往復で仕上がるのが普通**。一発で決まらないのは正常。

## クレジットを守るための禁止事項

- **HTML全文をチャットに貼らない**(ファイルパスを指すだけでよい)
- **「全体的に良くして」と言わない**。必ず場所を名指しする → 「20-hero の見出しを25字に縮めて」
- **1往復に修正をまとめる**。気づくたびに1件ずつ投げるのが一番高くつく
- **新規LPをゼロから生成させない**。必ず `_template` のコピーから始める
- **`base.css` をAIに書き直させない**。レイアウトが崩れたら「どのセクションのどの要素か」を名指しする
- **初稿の前にスクショ往復をしない**。まず出させてから直す
- 画像は仮のまま進め、**最後に実素材へ差し替える**。決済は作り込まず Stripe 決済リンクで足りる

## デザインの禁止則(AIっぽさを消す)

出典: `study/library/2026-07-10-codex-lp-5steps.md`

- 使わない書体: Inter / Roboto / Arial / システムフォント / Space Grotesk
- 角丸は8pxまで / グラデーションの光球なし / セクションは全幅の帯 / カードの入れ子なし / letter-spacing をマイナスにしない
- 色は4〜6色に役割をつけて固定、書体は2種、独自要素を1つだけ持つ(この型では「見出し左の縦罫」)

## 公開前チェック

`.company/CLAUDE.md` の共通憲法レビュー観点6項目と、`affiliate/CLAUDE.md` の品質基準6項目を通す。
特にこの2つはテンプレートに組み込み済みなので**消さないこと**: `10-nav.html` のPRバッジ、`95-footer.html` のPR表記・運営者情報。

## ファイル構成

```
_template/
  brief.md        記入用紙(先に埋める)
  tokens.css      色・書体・余白。案件ごとに触るのはここだけ
  base.css        共通レイアウト。原則触らない
  build.sh        sections/ を連結し index.html を出力
  sections/       00-head, 10-nav, 20-hero, 30-problem, 40-solution,
                  50-howto, 60-proof, 70-offer, 80-faq, 90-cta,
                  95-footer, 99-tail
```
